Aboutv1.1

Works with rotation lock on. Sideways, a keyboard appears on the screen instead of the iPhone one. The button at the start of the trackpad's key row switches too.

The same link as Lights. The relay prints it when it starts.
  1. On the PC, save pc_control.py into the relay folder (Documents\PhosphorLights), next to kasa_bridge.py, and save the new kasa_bridge.py over the old one.
  2. Close the relay window and start it again with py kasa_bridge.py.
  3. It should print PC control: on. Nothing else to install.

Files: phosphor-os/bridge. Only your own devices on Tailscale, holding the relay's secret key, can reach it.
