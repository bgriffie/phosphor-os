    Aboutv1.10

    Chromecasts on the same Wi-Fi as the PC show up here.

    The Today page on the TV shows this city's weather.
    Units

    Weather comes from Open-Meteo through the relay on your PC. Your city is kept there.

    The same link as Lights. The relay prints it when it starts.
    1. On the PC, open Command Prompt in the relay folder (Desktop\PhosphorLights) and run:
      curl -L -o tv_control.py https://raw.githubusercontent.com/bgriffie/phosphor-os/main/bridge/tv_control.py
      (Same for kasa_bridge.py the first time.)
    2. In Command Prompt in that folder, run py -m pip install pychromecast once.
    3. Close the relay window and start it with py kasa_bridge.py --cast. It should print TV: on.
    4. If Windows asks whether Python can use the network, tick Private networks only and Allow.

    Files: phosphor-os/bridge. The PC must be on the same Wi-Fi as the Chromecast.
