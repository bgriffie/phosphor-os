# Phosphor OS

A phone-style launcher in the PHOSPHOR theme: a grid of tiles that open iOS apps (app links and Shortcuts), Floyd's other tools, and built-in Phone, Notes and Calculator apps. Works offline.

Live: https://bgriffie.github.io/phosphor-os/

Edit `src/app.html` and `src/app.js`, then run `python3 build.py` to inline the shared PHOSPHOR CSS/JS into `index.html`. Bump the cache version in `sw.js` on every change.
